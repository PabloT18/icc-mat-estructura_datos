# Organización del trabajo del estudiante

No existe proyecto acumulativo. Las PC son actividades acotadas y las PL integran contenidos de su bloque. El proyecto final PL4.1 es una entrega autónoma de selección con presupuesto y programación dinámica.

Copia `plantillas/proyecto-estudiante/` para iniciar una entrega Java. El esqueleto contiene un punto de entrada y documentación, sin resolver algoritmos. Conserva fuentes en src, datos de entrada en datos cuando se necesiten y resultados reales en evidencias. La carpeta out contiene compilados locales y no se entrega.

Para PC en Python o JavaScript usa `plantillas/pc-python/` o `plantillas/pc-js/`. Escribe la implementación en main.py o main.mjs y registra los casos pedidos. La entrega de PC es una versión; no se exige traducirla a los tres lenguajes. Las PL se entregan solo en Java.

Las rúbricas de PL suman 10. Cada criterio admite máximo completo, mitad o cero, según los descriptores del HTML. No se añaden penalizaciones no documentadas. Las horas indicadas en cada PL son estimaciones pedagógicas, no horas oficiales nuevas.
