# Análisis de referencias

## Fuentes suministradas y función

- `ProgramaAnalitico_est.pdf`: fuente de alcance oficial, resultados, indicadores y carga horaria. Se entrega como `programa-analitico.pdf`.
- `icc-pap-material(1).zip`: referencia visual y técnica. Se inspeccionaron HTML, CSS, app.js, catálogo, generador, parser, fuentes, logos y una presentación renderizada. Se conservaron CSS y estructura de navegación y se adaptaron asignatura, unidades y selector de lenguajes. Se retiraron temas, dependencias y proyecto acumulativo ajenos.
- `01.01 MetodosOrdenamiento Directos.pdf`: profundidad inicial, inserción, selección y trazas.
- `01.02 MetodosOrdenamiento Avanzado.pdf`: Shell, Merge Sort y Quick Sort.
- `01.04 Recursividad.pdf`: caso base, pila, factorial y Fibonacci. El nombre del adjunto contiene dos espacios antes de Recursividad.
- `01-metodos-ordenamiento(1).html`: trazas, copias independientes, ambos sentidos y validación de menú, incorporados a PL2.1.
- `PL4.1-comparativa(1).html`: comparación situacional, Persona y evidencia de tiempos. Se integra en PL2.1 con tamaños obligatorios moderados y expansión opcional.
- `PL3.1-proyecto(1).html`: modelado de rutas, BFS/DFS, separación de lógica y vista, persistencia y defensa. Se adapta como PL3.3. La vista de mapa queda como ampliación; el núcleo obligatorio usa consola. PL4.1 es un proyecto autónomo de programación dinámica para cubrir esa unidad.
- XML de pilas, colas y búsqueda binaria: referencia de categorías, tipos y retroalimentación. Los 18 bancos de esta entrega son nuevos y usan numeración editorial. No se incorporan sin revisión categorías antiguas que situaban pilas y colas en Unidad 2.

## Correcciones respecto de ejemplos

El material distingue intercambio directo de burbuja por vecinos. La traza de selección conserva el prefijo ordenado. La versión de factorial elimina variables inexistentes y la llamada a un nombre de método distinto que aparecía en la referencia. El contrato evita desbordamiento y negativos. Shell explicita la secuencia de saltos. Quick Sort declara el peor caso y no se presenta como superior universalmente.

El orden de Persona se define con comparación por campos, sin combinar edad y suma de caracteres en un entero. Se evita afirmar que detección automática de IA pruebe autoría; se usan evidencias, explicación y modificación en defensa. Los tiempos de ejemplo no se presentan como mediciones propias.
