# Assets

Logos y fuentes provienen del ZIP suministrado; se conservan sus proporciones y licencia. styles.css conserva el diseño base y añade ajustes para selector de lenguaje y acciones.

catalogo.json, esquema 2: units, topics y labs conservan su estructura base. Cada versión tiene id único, code editorial compartido, official, language, path, deck, doc y quiz. prev y next mantienen el lenguaje. Las PL añaden directory para las carpetas descriptivas de unidad. protection controla la restricción superficial.

course-data.js es un archivo generado. Los contenidos MD no se sobrescriben al construir HTML. Los SVG son trazas exactas; los PPTX incluyen esas tablas como objetos editables. No se utilizaron imágenes generadas por IA para representar algoritmos.
